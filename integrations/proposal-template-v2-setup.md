# Proposal Template V2 rollout
The existing request and result Gmail subjects, database and LeadFlow UI stay unchanged. Legacy result with document_id continues to work. V2 adds format=template-v2 and content. GAS creates a new native Docs copy of a private master in the existing proposal folder, fills placeholders, exports PDF and returns actual IDs to LeadFlow. Previous proposals are untouched.

1. Open the private master provided by the owner. It must be owned by the same Gmail as GAS. Keep all placeholders intact (PROJECT_TITLE, CUSTOMER, INVESTMENT, DURATION, DATE, REFERENCE, CONTEXT, SOLUTION, OUTCOMES, SCOPE, BOUNDARIES, TIMELINE, DEPENDENCIES, PAYMENT, REFERENCES, NEXT_STEPS). The master can be restyled in Google Docs, but placeholders must remain intact in body text. No public sharing.
2. In the existing standalone Proposal Bridge GAS (not Finder), add Script Property PROPOSAL_TEMPLATE_ID with the master document ID. Do not alter endpoint or secrets.
3. Replace Code.gs with integrations/leadflow-proposal-bridge.gs from this branch. Run authorizeProposalTemplate and accept any new Docs permission. Deploy > Manage deployments > Edit > New version > Deploy, preserving the existing /exec URL.
4. Switch the Proposal Writer instructions to integrations/gpt-proposal-writer-v2.md only AFTER GAS V2 is deployed. Existing email event trigger is not proven active. A manual writer can test the new protocol.
5. In LeadFlow use Create revision on the dummy Aurora test with instruction to use the V2 template, or submit a new dummy. Confirm new request, self-email result with template-v2, new private Docs and PDF, status completed, and original proposal unchanged. Check PDF page fit and content. No need to redeploy Vercel or migrate Turso.
6. If needed roll back GAS to previous version and writer to V1; old results continue to work. V2 uses one fixed Premium Corporate layout; existing style field guides writing tone only. Long content can flow onto extra pages; visually inspect PDFs before approval. Form price and duration remain authoritative; create a new proposal for commercial changes.
